# Public image analysis

Open Images, choose Add images, select PNG/JPEG files and review every preview. Choose Use images, then explicitly select Analyze images. No inference occurs during upload or preview. The secure data source must enable vision and approve the selected model.

Up to 8 images, 4 MiB each and 12 MiB total are accepted subject to pixel and backend limits. Large images may be resized. Remove individual images, Remove all images or Clear analysis to discard pending attachments. Pending images are held in browser memory and are not saved in dashboard JSON.

For images only, turn off Include query data with images. For combined analysis, select Queries → Dashboard → Source panel to reuse a panel's results, and leave Include query data with images on. The plugin does not re-fetch source data to prepare uploaded images.

This edition has no dashboard capture, panel discovery or selected-panel capture. Upload a locally saved screenshot if visual context is needed. Other file formats are not supported.
